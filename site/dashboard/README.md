# dashboard/ — the Keeping

Eric and Mona's dashboard, behind Cloudflare Access (one-time PIN to their email).

Views: the year's calendar (tap a day to set its price, block it or set a minimum stay); seasons and weekend rules; bookings, payments, refunds; guests; words waiting for approval; the ideas board (heard, planned, built, credited); the media slots by place and season (real or imagined).

Nothing is ever deleted; cancelled bookings and retired records are marked.
