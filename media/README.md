# media/ — originals

The photos and video exactly as they came from the shoots. **Never edit, rename, move or recompress anything here.** Web copies are made into `site/assets/media/` by `scripts/make-web-media.sh`.

Every file has a row in the Airtable Media table (base "The Dome") with the same file name: what it shows, its places, season, people in frame and whether it may be used. Check that row before using a file.
